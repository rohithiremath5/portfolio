These are the existing portfolio fonts, hosted locally to remove third-party
stylesheet requests. WOFF2 Latin subsets were downloaded from Google Fonts.
DM Sans is a variable font covering the existing weights. DM Serif Display
includes normal and italic; Space Mono uses the existing normal weight.
See the corresponding *-OFL.txt files for copyright and SIL Open Font License.
If adding languages outside the Latin subset, obtain the required subsets too.
