# Skill logos

Only the individual SVG assets used in the Technical Skills section are vendored.
They are unmodified, served locally, and require no icon font, CDN, or runtime package.
The exact upstream URL for each asset is recorded in `sources.json`.

- Devicon: commit `32fe1d3b3f36ad11f90ab94f7db59738139c2bf6` of
  https://github.com/devicons/devicon. MIT license retained in `DEVICON-LICENSE.txt`.
- Simple Icons: version `11.15.0` of https://github.com/simple-icons/simple-icons,
  for CSS Modules, OpenAI, and Linux. CC0 text retained in `SIMPLE-ICONS-LICENSE.md`.
- LangChain and LangGraph: unmodified Simple Icons assets retrieved from its
  `develop` branch on November 27, 2026; exact sources are in `sources.json`.
  The same retained CC0 license applies.

Brand marks remain the property of their respective owners. They identify the
technologies listed in the portfolio and do not imply endorsement. React's mark
also represents React Native. General concepts use the already-installed Lucide
icons instead of invented brand marks. CSS provides a contrasting surface for cyan
marks and inverts monochrome marks in dark mode; the SVG files themselves are unchanged.
